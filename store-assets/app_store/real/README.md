# Real iPhone screenshots for App Store Connect

Captured on a physical iPhone from the live app (demo organisation data; no personal names).
Sources were 591x1280 WhatsApp copies, so they are upscaled. Status bar removed and the
top padded white so every file is the exact size App Store Connect accepts.

- iphone_6.9in_1320x2868: iPhone 6.9" display
- iphone_6.3in_1206x2622: iPhone 6.1" / 6.3" display

Order: sign-in, home, tyre inspection (ready for review), damaged tyre detail,
pickup inspection, fleet and assets, open services, accident command centre.

For sharper store images, replace with full-resolution screenshots taken on the phone
(AirDrop or Files, not WhatsApp) and rebuild at the same sizes.
Not covered: iPad 13" and foldable sizes; the existing generated sets remain for those.
