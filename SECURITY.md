# Security Policy

## Supported Versions

Only the latest production version of Tyre Pulse is currently supported with security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Security vulnerabilities should be reported privately through GitHub's security reporting features.

Include:
- Description of the vulnerability
- Steps to reproduce
- Affected screen/API/module
- Potential impact
- Screenshots or logs where applicable

We will review reported vulnerabilities and prioritize fixes according to severity.
