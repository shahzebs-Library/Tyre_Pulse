# Production-Level Implementation Rule

## Core Philosophy
Anything built for this project must be fully advanced and at a production-level standard. Never implement shallow stubs without a deep understanding of how the feature should behave in a real-world scenario.

## Requirements
- Understand the complete behavior of a feature before writing code.
- Ensure that edge cases, state management, and real-world workflows are fully accounted for.
- Mimic the complexity and completeness found in other parts of the application (e.g., maintaining consistency between mobile app features and web app features).
- When asked to add modules (like Washing or Accidents), translate them completely and correctly into the frontend with all necessary UI/UX routing and state logic.
