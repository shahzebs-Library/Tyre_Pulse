# UI/UX CONTRACT

## Visual Principles
- **Enterprise Grade**: Clean, operational, and compact.
- **Dual Theme**: Support OLED Pure Black (#000000) for field work and White (#FFFFFF) for office work.
- **Safety Primary**: Use Safety Yellow (#FFD700) for primary actions and branding.

## Layout Rules
- **Compactness**: High information density for field operators.
- **Fast Interactions**: Minimize animations; prioritize touch response.
- **Consistency**: Use standardized cards, buttons, and text styles. Avoid decorative dashboards.

## Interaction Design
- **Offline Awareness**: Show clear banners when offline.
- **Form Preservation**: Save drafts automatically.
- **Haptic Feedback**: Use on critical success/error events.
